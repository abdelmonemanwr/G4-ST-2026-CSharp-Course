# C# & OOP Summer Training Bootcamp 🚀

Welcome to the official repository for the **C# & Object-Oriented Programming (OOP) Summer Training Bootcamp**. This repository contains all the reference materials, code examples, and daily lab assignments designed to take you from C# basics to advanced OOP architectural thinking.

## 📌 Course Overview

This 7-day intensive bootcamp is structured to provide a balance between theoretical concepts (3 hours/day) and practical implementation (3 hours/day). By the end of this training, you will be equipped with the foundational skills needed to write clean, robust, and scalable backend applications using .NET.

## 📅 Daily Agenda

* **Day 1:** Intro, Setup Visual Studio, Variables & Casting
* **Day 2:** I/O, Value vs Ref, Control Flow & 1D Arrays
* **Day 3:** Multi-Dim Arrays, Structs & Properties
* **Day 4:** Overloading, Classes & Constructors
* **Day 5:** Inheritance, Override, Static, Abstract & Sealed
* **Day 6:** Generics, Collections, Foreach & System.Object
* **Day 7:** Delegates, Anonymous Methods & Parameters

## 💻 Repository Structure

* `/Day01_to_Day07`: Folders containing the daily lecture code snippets and examples.
* `/Labs`: Daily practical assignments and exercises to be completed during the lab sessions.

Before starting the labs, ensure you have the following installed:

* [Visual Studio 2022 (or newer)](https://visualstudio.microsoft.com/) with the **.NET desktop development** workload.
* .NET SDK installed on your machine.
